# Tower Jump

An Icy Tower–style vertical climber. Build speed along a floor, then convert it into a jump
big enough to clear several platforms at once — while the bottom of the tower shakes loose
and falls away beneath you.

**▶ Play: https://maneghazaryan.github.io/tower-jump/**

## Controls

| | Keyboard | Touch |
|---|---|---|
| Move | `A` / `D` or `←` / `→` | left and right pads |
| Jump | `Space`, `W` or `↑` | jump pad |

Hold a direction to build speed: the faster you are moving when you jump, the higher you go.
A jump at a standstill clears exactly one floor. Standing still for a moment bleeds your
momentum away, so keep moving.

## About this repository

This holds the published WebGL build only — it is the artifact GitHub Pages serves. The Unity
project it is built from is kept in a separate private repository.

Built with Unity 6000.3.25f1.
